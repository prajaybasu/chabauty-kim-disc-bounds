# A zero estimate for triangular logarithmic systems and residue discs in Chabauty–Kim loci

Prajay Basu · prajay@prajaybasu.com

[Read the manuscript](manuscript.pdf) · [Build the paper and reproduce the computations](paper/README.md)

The paper bounds the order of vanishing for triangular logarithmic systems in characteristic *p* and applies the estimate to residue discs in fixed-depth Chabauty–Kim loci. The companion code includes the Lean development, the finite-field screens and the independent lifting checks used in the paper.
